# macropad
4x4 Keyboard with Rotary Encoder

## What is it?
It is a basic keyboard made following tutorial from Hack Club Blueprint

## Why did I build it?
To teach my brother building stuff, I teamed with him and explained how to design PCB

## How to recreate it?
1. 3D Print enclosure
2. Buy parts and PCB
3. Solder parts
4. Assemble parts in enclosure
5. Flush firmware
6. Enjoy
